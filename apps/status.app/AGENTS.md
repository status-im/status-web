# apps/status.app

Rules for agents working in `apps/status.app`. The root `AGENTS.md` also applies.

## Role

Next.js 15 app behind https://status.app: marketing site, help centre, specs hub, blog and admin
tooling. Port 3001. `content/` is published site content, never code documentation.

## Commands

- `pnpm --filter status.app dev:next`: dev server on :3001.
- `pnpm --filter status.app dev:content`: watch `content/` and rebuild Contentlayer.
- `pnpm --filter status.app build`: `lint` (remark and eslint), blog search index, then `next build`.
- `pnpm --filter status.app test`: vitest.
- `pnpm --filter status.app types:check`: Contentlayer build, then `tsc`.
- `pnpm --filter status.app codegen`: regenerate GraphQL types from `codegen.yml`.
- `pnpm --filter status.app sync:cloudinary`: regenerate Cloudinary asset types.
- `pnpm --filter status.app db:generate` / `db:push` / `db:explore` / `db:check`: Drizzle.
- `pnpm --filter status.app env:check`: validate `.env` against the Zod schemas.
- `pnpm --filter status.app lint:remark`: lint `content/help` and `content/legal`.
- `pnpm --filter status.app knip`: find unused exports and dependencies.

## Rules

- Leave `content/**` alone during code work. It is site content (help centre, legal, the `specs`
  submodule, the editorial `style-guide`) and it ships to readers.
- Drizzle owns the schema in `src/server/db/schema/*`. Change it, run `db:generate` and commit the
  SQL it writes under `migrations/`. Never hand-edit a generated migration. `db:push` only against
  a database you can throw away.
- The GraphQL types in `src/app/(website)/insights/_graphql/generated/` are generated from
  `codegen.yml`. Regenerate them instead of editing them.
- `src/app/_components/assets/types.ts` is generated by `sync:cloudinary`. Regenerate it.
- Markdown under `content/help` and `content/legal` must pass `lint:remark` (remark-lint and
  prettier). Run it when you touch either.
- Keep the Zod schemas in `src/config/env.{server,client}.mjs` in step with `.env.example`. Nothing
  runs `env:check` for you, and the build only catches a missing variable because `next.config.mjs`
  imports the schemas.

## Caveats

- `content/specs` is a git submodule. `scripts/ensure-specs-content.mjs` runs before Contentlayer
  and fails the build rather than ship an empty `/specs` hub; see [self-hosting](docs/self-hosting.md).
- `.contentlayer/` is generated and gitignored. `prelint`, `build` and `next dev` rewrite it, and
  `pnpm --filter status.app clean` removes it when content looks stale.
- The generated GraphQL files are listed in `knip.ignore` in `package.json`. Keep those entries if
  you move the folder.
- There is no `dev` script in this app, only `dev:next`. `db:explore` starts Drizzle Studio on 3001,
  the same port, so stop the dev server first.
